How It Works

A 3-step process takes your uploaded image through preprocessing, neural inference, and forensic report generation — all within 1.5 seconds on standard CPU hardware.

01
Upload Media
Drag or drop a face image (PNG, JPG, JPEG, WEBP — up to 10MB) into the neural analysis workspace. Your file is instantly previewed with cyberpunk targeting crosshairs.
02
EfficientNet AI Processing
The EfficientNet-B0 model preprocesses to 224×224, normalizes with ImageNet statistics, runs a forward tensor pass, and applies Softmax to output real vs. fake probabilities.
03
Verify Authenticity
Receive an AUTHENTIC or MANIPULATED verdict with an animated SVG radial gauge, probability bars, and comprehensive forensic diagnostic bullet points — instantly.

Technical Architecture

Under the Hood

Built on a fine-tuned EfficientNet-B0 CNN paired with an ephemeral Flask WSGI backend — delivering forensic-grade analysis with a zero-retention privacy model.

EfficientNet-B0 CNN

torchvision · 16.3 MB · CPU optimized

Compound scaling simultaneously balances depth, width, and resolution. Mobile Inverted Bottleneck convolutions (MBConv) with Squeeze-and-Excitation attention capture subtle pixel-level generative artifacts. The ImageNet classification head is replaced with a binary projection: nn.Linear(1280, 2).

Resize → 224 × 224 (Pillow)
Normalize with ImageNet mean/std
Unsqueeze to [1, 3, 224, 224] tensor
Forward pass → Softmax probabilities
Threshold comparison → REAL / FAKE verdict

4-Class Forensics Dataset

HuggingFace · OpenCV Haar Filter · PIL Augmentation

A curated 4-class facial forensics dataset harvested from HuggingFace corpora, filtered through OpenCV Haar Cascade face detection, and augmented with procedural PIL manipulations.

Real — CelebA Faces Synthetic — AI Generated Cartoon — Stylized Manipulated — Procedural

Manipulations include: splice (face transplant + Gaussian blur), light (radial illumination anomalies), warp (quadrant scaling via Lanczos), and filter (saturation / blur / pixelation).

Flask WSGI Backend

Flask 3.1.3 · Flask-CORS 6.0.5 · PyTorch 2.13

Single-load model initialization at startup eliminates per-request disk I/O, enabling sub-100ms tensor pass latency. The /detect endpoint validates extensions against a whitelist, writes to a UUID-named temp file, and deletes it deterministically via finally: os.remove().

POST /detect — multipart/form-data
GET /health — model diagnostics endpoint
Allowed: PNG, JPG, JPEG, WEBP ≤ 10MB
Port 5000 · CORS enabled · Stateless REST

Ephemeral Privacy Architecture

Zero SQL/NoSQL · 100% Biometric Privacy

No database is used. Facial images uploaded by users are strictly transient — processed in volatile memory and OS temp storage, then immediately unlinked. No biometric data is ever stored, logged, or transmitted to third parties.

UUID-named temp file — collision-free
Processed in RAM — never persisted to disk
os.remove() in finally block — guaranteed cleanup
Zero hardcoded secrets or database strings
