Everything you need to know about our deep learning model architecture, biometric safety, supported media formats, and classification confidence.

Our EfficientNet-B0 model achieves ~99.2% accuracy on benchmark test partitions. However, no AI system can guarantee 100% precision on all images — particularly heavily compressed, degraded, or multi-filtered social media thumbnails. We recommend using our reports as high-confidence analytical forensic evidence alongside human verification.

No. We operate on a strict 100% biometric privacy principle. When an image is uploaded for inference, it is temporarily processed in ephemeral memory and deleted immediately via Python's os.remove() deterministic cleanup inside a finally block. Zero images are stored in permanent databases.

We accept PNG, JPG, JPEG, WEBP, BMP, and TIFF files up to 10MB in file size. For optimal detection performance, clear portrait images with prominent facial features and resolution above 224×224 pixels produce the most reliable forensic results.

The current production release focuses on static portrait imagery. Continuous temporal video sequence analysis (frame extraction + recurrent temporal consistency modeling) is currently on our future development roadmap.

The neural network uses an EfficientNet-B0 backbone fine-tuned on the DF-DATASET (~139,114 images) comprising authentic portraits (CelebA, FFHQ) and adversarial manipulated/generative classes (StyleGAN, Stable Diffusion, procedural splicing, and warping). Training incorporated balanced class weighting, early stopping, and validation threshold calibration.
